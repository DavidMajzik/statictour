Putting it on your website:

  1. Unzip it. You get a tour/ folder with index.html, pannellum.js, pannellum.css, tour.json and an images/ folder.
  2. Upload the whole tour/ folder to your web server (FTP, cPanel, Netlify, GitHub Pages, S3 – anything that serves static files).
  3. Open https://yourdomain.com/tour/. That is the tour. No backend, no API keys, nothing else to run.
  4. Keep the tour.zip on your computer: 📂 Open tour lets you re-open and edit it later.
